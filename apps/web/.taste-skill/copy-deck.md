## Inside a report
Heading: Inside a report
- The hallmark — Rating, fineness and date, struck in one row.
- Loop detection — Money a seller sends back into its own loop is netted out.
- Funding trace — Payers the seller funded, even one hop back, count for nothing.
- Pre-payment check — Pass, caution or block, before the money moves.
- Self Agent ID — Payers proven to be one human count once.
- ERC-8004 identity — Linked to the agent's onchain registration.
- Priced per call — Agents pay $0.002 in USA₮ over x402.
- Signed score — EIP-712, verified by AssayRegistry on Celo.
